Repositorio de trabajo para el desarrollo del sitio institucional y la plataforma de alumnos de **INISCH** (Instituto Internacional del Sistema Código Holográfico).

## Estructura

```
/docs      -> Documentación de planeación del proyecto
/site      -> Propuestas de diseño del sitio web (HTML/CSS estático, sin build)
/assets    -> Logotipo e imágenes de marca (pendiente subir manualmente, ver abajo)
```

## ⚠️ Pendiente: subir imágenes de marca a `/assets`

Para que las 2 propuestas se vean completas, sube estos 2 archivos (los mismos que ya tienes en tu computadora) a la carpeta `assets/` del repositorio, con estos nombres exactos:

- `assets/LOGO_INISCH_NUEVO_png_copia__1_.png` — logotipo completo (emblema + texto)
- `assets/Screenshot_2026-09-02_at_1_44_09_PM.png` — banner de marca (fondo marmoleado con logo)

Cómo subirlos (sin necesidad de Git ni terminal):
1. Entra a https://github.com/fondosdharma-a11y/inisch-web
2. Entra a la carpeta `assets`
3. Botón **Add file → Upload files**
4. Arrastra los 2 archivos desde tu computadora y da **Commit changes**

En cuanto estén ahí, las propuestas en `/site` los mostrarán automáticamente (ya están referenciados en el HTML).
